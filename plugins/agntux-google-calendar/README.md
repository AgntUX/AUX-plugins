# agntux-google-calendar

See your day ahead, with helpful notes for each meeting pulled from your past messages and notes.

## Overview

The Google Calendar plugin reads your upcoming meetings, creates a to-do for each one, and gathers helpful notes — related Slack threads, Gmail conversations, and past notes — so you're prepared before each one.

## Features

- **Daily look-ahead**: Each morning, reads your meetings for the next 7 days across all your calendars
- **Prep notes**: Automatically gathers related messages and notes to help you prepare
- **Schedule meetings**: Find-a-time via Google Calendar's suggest_time API and create events directly
- **Respond to invites**: Accept, tentatively accept, or decline invites with optional notes to organiser
- **Conflict detection**: Highlights double-bookings and overlapping critical meetings

## Installation

The plugin requires the `agntux-core` plugin and Google Calendar MCP connector.
