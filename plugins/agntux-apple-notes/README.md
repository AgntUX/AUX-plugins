# agntux-apple-notes

Bring Apple Notes into AgntUX with one-click actions to create and update notes.

## What it does

Apple Notes syncs into AgntUX so you can see action items and reminders in one place. You can create new notes, update existing ones, and check off items from your phone's native note app — all from AgntUX.

## Features

- **Check for new notes** — Automatically syncs every 4 hours to find new and updated notes.
- **Create notes** — Compose and save new notes to Apple Notes directly from AgntUX.
- **Update notes** — Edit existing notes, add content, or check off checklist items.
- **Smart deduplication** — Tracks notes by stable ID and modification time to avoid duplicates.

## Getting started

1. Install the plugin from the AgntUX marketplace.
2. Set up the Apple Notes connector.
3. Type `/agntux-apple-notes` to check for new notes or ask questions about your notes.
4. Use the Create Note and Update Note buttons to manage your notes.
